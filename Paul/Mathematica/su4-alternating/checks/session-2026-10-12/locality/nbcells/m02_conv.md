## Conventions and algorithm

Chain A F A F A F (site 1 = A), bras are row vectors, ψ·M. Lax 𝓛_A = (u−θ) + hK, 𝓛_F = (u−θ) − hP on aux⊗site; T(u) = 𝓛₁⋯𝓛_{2L} (site 1 leftmost), twist on the right, diagonal twist Λ = diag(z). t₁ = tr(T Λ); t₂ = ∏g⁽²⁾ tr[𝓛⁽²⁾₁⋯ ∧²Λ] (6-dim aux, F shifted by h, g⁽²⁾_A = u−θ−h, g⁽²⁾_F = u−θ); t₃ = ∏g tr[𝓛̄₁⋯ det Λ·Λ^{−T}] (𝓛̄_A = (u−θ+h) − hP, 𝓛̄_F = (u−θ−3h) + hK). Point: h = 1/2, θ = (2/7, −3/5, 8/11, −11/8, 5/13, −7/9), z = (3/2, 5/4, 2/3, 4/7); second point θ′ = (1/3, −2/5, 3/4, −5/4, 2/9, −7/10) — **non-generic**: θ₃ − θ₄ = 4h (cyclic dimensions 48/534 instead of the generic 54/588; layer structure unchanged); third, generic point θ″ = (19/23, 34/29, 41/40, −19/12, −7/11, 13/17).

All spans/ranks/memberships are done **exactly modulo a prime p < 2²²** (all entries are integers < 2²², every contraction has ≤ 24 terms, so machine doubles are exact; `Mod` after every site). The pass is the one-pass vector form (Φ[i,k] = ψδ_ik, Φ′[i,l] = Σ_{k,a} Φ[i,k][..a..]·Lax[k,l,a,b], trace with the diagonal twist). Calibration: ⟨W_a^{⊗L}|t₁(θ₁)⁻¹ = c₁⟨W_a^{⊗L}|ρ₁(Λ⁻¹) holds exactly for W_a^{⊗L} (a global rotation of the vacuum) but **not** for an arbitrary product bra, not even for W_{a′}⊗W_a^{⊗(L−1)} (the task text “any product bra” must be read as “any globally rotated vacuum”).
